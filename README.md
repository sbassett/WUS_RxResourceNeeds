# WUS_RxResourceNeeds
Modeling the resources (personnel, quals, and equipment) needed to restore low-intensity wildfire regimes in the western United States.

## Repository Structure

```
WUS_RxResourceNeeds/
├── data/
│   ├── raw/          # Read-only original datasets. Do not manually edit files in this folder.
│   └── processed/    # Intermediate and final datasets generated by the analysis scripts.
├── scripts/          # R scripts, numbered sequentially (e.g., 01_data_cleaning.R, 02_analysis.R)
│                     # to indicate the order of execution.
├── results/
│   ├── figures/      # Generated plots and maps.
│   └── tables/       # Generated summary tables.
└── docs/             # Documentation, technical notes, and manuscript files (e.g., R Markdown).
```
